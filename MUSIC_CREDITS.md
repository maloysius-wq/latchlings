Last verified: 2026-08-31

License: https://creativecommons.org/publicdomain/zero/1.0/

CC0 does **not require attribution**. The credits below are intentionally preserved anyway so the project retains a clear provenance trail and creators receive voluntary credit.

The shipping game copies are normalized/transcoded derivatives of the source audio for consistent browser playback and volume. Encoding/loudness processing does not change the underlying licensing.

## Binary-source provenance

For reliable repository import, the CC0 source files were retrieved from the public archival repository:

- https://github.com/euuuuuuan/todak-public
- provenance ledger: `assets/music/LICENCES.json` in that repository

That archive identifies the selected files as CC0 and links back to the original OpenGameArt or Free Music Archive source pages above. The original source pages are the primary human-readable licensing references for this project.

## Processing performed for Latchlings

The source archive copies were OGG/Vorbis. The Latchlings copies are converted for broad mobile-browser compatibility with FFmpeg and normalized approximately to:

- integrated loudness: -20 LUFS
- true peak target: -2 dBTP
- loudness range target: 7 LU
- MP3 encoding: LAME variable quality (`-q:a 5`)

Keep this file with the project if the soundtrack is redistributed. Attribution is not legally required by these CC0 selections, but provenance should remain documented.
