# Latchlings Title Concept Preview - Asset Sources

The ten title-page previews are real HTML/CSS/JavaScript concepts. The Latchling characters, nests, UI layouts, scene composition, and most decorative elements are original HTML/CSS/SVG created for the Latchlings project.

A small number of environmental accent sprites are used from **Kenney** asset packs. These assets are released under **Creative Commons CC0 1.0 Universal**, meaning attribution is not legally required and commercial use is allowed. Provenance is recorded anyway.

## Kenney - Background Elements Remastered

- Original pack: https://kenney.nl/assets/background-elements-remastered
- License: CC0 1.0 Universal
- License URL: https://creativecommons.org/publicdomain/zero/1.0/
- Human-made source pack; Kenney's asset page identifies the pack as CC0.
- Transfer source used for the preview: `Tiddybub/2d-assets`, a public curated CC0 mirror whose `SOURCE.md` points back to the Kenney pack.

## Other researched CC0 packs

These packs were reviewed as possible production sources and are also CC0, but the current preview does not need to ship all of them:

- Kenney **UI Pack - Adventure** - https://kenney.nl/assets/ui-pack-adventure - CC0
- Kenney **Fantasy UI Borders** - https://kenney.nl/assets/fantasy-ui-borders - CC0
- Kenney **Foliage Sprites** - https://kenney.nl/assets/foliage-sprites - CC0
- Wenrexa **Free UI Flowers / Nature Kit Interface** on OpenGameArt - CC0

The preview deliberately avoids leaning too heavily on third-party UI art. The goal is for the final title page to develop a recognizable Latchlings identity rather than resemble an off-the-shelf asset pack.
